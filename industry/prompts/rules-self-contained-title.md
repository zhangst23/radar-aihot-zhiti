
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：原料名（含规格或学名）/ 公司名 / 法规或批准编号 / 展会名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "v2.1.159"、"Small is a feature"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "v2.1.159" + 来源 "Claude Code：GitHub Releases" → "Claude Code v2.1.159 发布"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体品种时，用上位词（如“一种植物提取物”“一款食品添加剂”）兜底，绝不凭“行业常识”编一个具体品种 / 规格 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、科普或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的原料、产品或新数据，就改写成“发布 / 推出 / 获批 / 上市”。只有原标题明确宣布了发布、获批或上市，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、原料、法规名。
   例：原标题 "How curcumin bioavailability varies with formulation" → "姜黄素的生物利用度如何随配方变化"，不能写成 "某公司推出高吸收姜黄素"。
   例：原标题 "How to read an EFSA novel food opinion" + 来源和正文明确是 EFSA → "EFSA 新型食品意见怎么看"，不能只写成缺主体的 "新型食品意见怎么看"。
6. 本条的动作和背景里的旧发布要分清：原文把批准或发布写成过去的事（“Last year EFSA approved …”“去年获批的…”），本条是在讲用法、做回顾或再次推广时，标题写介绍、讲解或分析，把批准/发布交代成此前的事；不能写成“获批 / 推出 / 上市”，否则读者会当成今天的新闻。只有原文明确某个品种或用途是现在才获批或开放，才对那一项用对应动作。
   例：正文 "The extract was authorised in 2024. Here is how brands use it" → "2024 年获批的这款提取物，品牌现在怎么用"，不能写成 "该提取物获批"。
