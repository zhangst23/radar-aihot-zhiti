1. 歧义默认值：以下词在中文有非原料歧义，**一律按原料行业含义翻译**：
   - API = 原料药（Active Pharmaceutical Ingredient），绝不译“应用程序接口”；只有原文明确指软件接口时才写“软件 API”
   - Excipient = 药用辅料（不译“赋形剂”以外的口语说法，全文统一）
   - Intermediate = 医药中间体（不是“中间产品”“中转环节”）
   - Formulation = 配方；药品语境可写“制剂”，同一篇里保持一致
   - Botanical / Botanicals = 植物原料 / 植物药（按语境），不译“植物学的”
   - Botanical extract = 植物提取物；Standardized extract = 标准化提取物
   - Extract ratio = 提取比（如 10:1 原样保留）
   - Marker compound = 标志性成分（不是“标记物”“指标物”）
   - GRAS = 一般认为安全（GRAS），保留缩写
   - Novel food = 新型食品（欧盟语境）/ 新食品原料（中国语境），按原文法规体系选
   - Food additive = 食品添加剂；Processing aid = 加工助剂
   - Carrier = 载体；Encapsulation = 包埋 / 微胶囊化（按原文）
   - Clean label = 清洁标签
   - INCI = 国际化妆品原料命名（保留 INCI）
   - Surfactant = 表面活性剂；Humectant = 保湿剂；Emollient = 润肤剂；Active = 活性成分
   - Peptide = 肽；Protein hydrolysate = 蛋白水解物；Polysaccharide = 多糖
   - Saponin = 皂苷；Flavonoid = 黄酮；Anthocyanin = 花青素；Carotenoid = 类胡萝卜素
   - Bioavailability = 生物利用度；Sensory = 感官；Taste masking = 掩味
   - Contract manufacturing = 委托生产；CDMO = 合同研发生产组织（保留 CDMO）

2. 以下专有名词**一律保留英文原文和原始写法**，不翻译、不改大小写、不加中文括注：
   - 监管机构与法规缩写：FDA / EFSA / EMA / NMPA / FSA / FSANZ / TGA / Health Canada / USP / EP / ChP / JP / GMP / DMF / CEP / NDI / GRAS / INCI / IFRA / REACH / CLP / E 编号
   - 原料名：Omega-3 / EPA / DHA / CLA / MCT / CBD / CBG / NMN / NR / PQQ / CoQ10 / SOD / HA
   - 规格与工艺缩写：CAS 号 / HPLC / GC / MS / NMR / UV / CFU / IU / ppm / ppb / Da / kDa / MW / pH / Aw / Brix / TPC / TBA
   - 公司与品牌：ADM / Cargill / DSM-Firmenich / Givaudan / IFF / Symrise / BASF / Croda / Lonza / Evonik / Ingredion / Tate & Lyle / Kerry / Roquette / BENEO / Novonesis / Indena / Sabinsa / Martin Bauer / Kalsec
   - 展会与组织：Fi Europe / Fi Asia / Vitafoods / SupplySide / CPHI / in-cosmetics / IFEAT / IFT / WPC / IPA / CRN
   - **规则**：任何原料代码、菌株编号（如 ATCC 12345、LGG）、CAS 号、法规编号（如 (EU) 2023/1234）、E 编号一律原样保留，不翻译、不改造

3. 学名与中文名：
   - 拉丁学名（如 Curcuma longa、Panax ginseng、Boswellia serrata、Withania somnifera）保留原文，首次出现可接中文常用名
   - 中文常用名与商品名不一致时（如 ashwagandha 南非醉茄/印度人参、turmeric 姜黄），首次出现写“中文常用名（英文）”，之后选一种保持一致
   - 中国厂商优先用官方中文品牌名，首次出现可双标，如“嘉吉（Cargill）”“帝斯曼-芬美意”“奇华顿”“巴斯夫”“禾大”“龙沙”“宜瑞安”“凯爱瑞”“诺和新元（Novonesis）”
   - 不要把“某公司的原料商品名”改写成通用成分名；商品名保留原样，通用成分名放在其后

4. 数字 / 单位 / 网址 **一字不改**保留：
   - 含量、纯度、剂量、比例、区间、价格：98%、5 mg/kg、500 mg、2 g/天、10:1、$12/kg、€3.5/kg、CFU/g、IU、ppm
   - 金额、数量、比例、区间必须保留原文的阿拉伯数字和单位；不要把 $10/kg 改写成“每公斤十美元”，不要把 1,000 t 改写成“上千吨”
   - 日期与地区：2026-11-16、Q1 2027、EU、US、Mercosur 原样保留；需要时补中文地区名，但不替换原文缩写
   - URL、法规链接、DOI 原样保留
   - 不确定的数字宁可不写，不四舍五入、不换算、不补单位
